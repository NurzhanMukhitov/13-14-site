# 13|14 — сайт-портфолио (хэндовер)

Персональный сайт **Nurzhan Mukhitov** — Technical Director & Producer живых
брендовых событий. Чисто личная визитка — слово «Studio» не используется;
знак «13|14» — личный. Контакт: info@13-14.space.

## Стек и запуск

- **Next.js 16** (Turbopack, App Router, RSC), **React 19**, **Tailwind v4**,
  **shadcn/ui** (new-york), **React Bits** ProfileCard, `lucide-react`.
- Запуск: `npm run dev` → `http://localhost:3000`.
- Деплой: проект привязан к Vercel; на `13-14-site.vercel.app` пока **старая
  версия** (изменения только локально, не задеплоены).

## Структура

- `app/page.tsx` — **вся страница**: Profile + 10 экранов проектов. Вертикальный
  полноэкранный скроллер, sticky-секции, JS-снап, reveal-blur, шторка-вуаль при накрытии.
- `app/layout.tsx` — метаданные. ⚠️ **title всё ещё «Digital visual artist»** —
  наследие шаблона, поменять на 13|14 / Nurzhan.
- `components/ProfileCard.tsx` + `ProfileCard.css` — карточка профиля (React Bits),
  сильно кастомизирована (см. блок «Кастом 13|14» в конце CSS).
- `components/Slideshow.tsx` — авто-слайдшоу с кросс-фейдом для проектов.
- `public/cases/<slug>/1..N.jpg` — фото проектов (3–4 на проект).
- `public/profile/photo.jpg` — портрет для карточки.
