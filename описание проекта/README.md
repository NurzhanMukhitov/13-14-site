## Концепция сайта

Горизонтальный скролл (snap-x). Каждый экран — отдельная "страница":

| # | Экран | Тема |
|---|-------|------|
| 1 | **TITLE** — `13 \| 14` по центру | Белый |
| 2 | **PROJECT 001** — заглушка | Чёрный |
| 3 | **PROJECT 002** — заглушка | Белый |
| 4 | **PROJECT 003** — заглушка | Чёрный |
| 5 | **PROJECT 004** — заглушка | Белый |
| 6 | **PROFILE** — сфера слева, тексты справа | Чёрный |

Навигация — фиксированная строка сверху: `TITLE · PROJECT 001 · PROJECT 002 · PROJECT 003 · PROJECT 004 · PROFILE`.  
Активный пункт подсвечивается при скролле.

## Интерактивная сфера

Главный визуальный элемент — сфера из частиц (цифры `1`, `3`, `4`).  
Реагирует на мышь: частицы разлетаются от курсора и возвращаются обратно.

**Текущая реализация:** p5.js — `components/sphere-canvas.tsx`  
**Параметры:**
- Desktop: 8000 частиц, радиус 250px, repel radius 90px
- Mobile: 4000 частиц, радиус 160px, repel radius 60px
- Attraction: 0.01 / Damping: 0.9 / Repel strength: 28
- Вращение: `angle += 0.01` за кадр

**Экспериментальный WebGL-вариант:** `components/sphere-r3f.tsx` (@react-three/fiber) — не подключён, в разработке.
